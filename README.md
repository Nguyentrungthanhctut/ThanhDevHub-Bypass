## 📖 Giới thiệu

ThanhDevHub-Bypass là website chia sẻ prompt AI,
hỗ trợ tùy chỉnh cách phản hồi và nâng cao trải nghiệm
sử dụng các nền tảng trí tuệ nhân tạo.

Website được xây dựng bằng HTML, CSS và JavaScript
với giao diện Dark Neon hiện đại.

## ✨ Tính năng

- Giao diện Dark Neon hiện đại.
- Hiệu ứng Loading 0–100%.
- Thông báo chào mừng và slogan.
- Thư viện AI Prompt.
- Tải xuống file TXT.
- Sao chép prompt nhanh chóng.
- Hướng dẫn sử dụng trực quan.
- Tương thích máy tính và điện thoại.
- Không yêu cầu API Key để sử dụng website.

## 🚀 Hướng dẫn sử dụng

1. Truy cập website ThanhDevHub-Bypass.
2. Nhấn nút Bắt đầu.
3. Chọn prompt phù hợp với nền tảng AI.
4. Tải xuống file TXT hoặc sao chép nội dung.
5. Mở cuộc trò chuyện mới trên nền tảng AI.
6. Gửi prompt để thiết lập cách phản hồi.
7. Nhập yêu cầu cần AI hỗ trợ.

Hiệu quả phụ thuộc vào nền tảng và phiên bản AI.
